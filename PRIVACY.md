# Privacy

Minimal Startpage for Firefox does not collect analytics, telemetry, advertising data, or personal information for the developer.

Search terms are sent only to the search engine selected by the user.

If Unsplash wallpapers are enabled, the user's Unsplash Access Key and selected collection IDs are sent directly to the Unsplash API for wallpaper requests.

Quicklinks, quotes, appearance settings, search-engine preferences, and Unsplash configuration are stored locally in Firefox.

No user data is sent to, stored by, sold by, or shared with the developer.
